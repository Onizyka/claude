# Инвентаризация ЦОД — Android-приложение

Приложение для учёта нового оборудования при монтаже в стойку. Заполняете карточку,
нажимаете «Отправить», и отчёт уходит письмом на адреса из настроек.

## Возможности

- **Место установки задаётся один раз:** при первом запуске приложение спрашивает площадку,
  помещение (машзал) и, если нужно, стойку. Дальше эти данные подставляются во все записи.
  Сменить место можно кнопкой «Изменить» в блоке «Размещение».
- **Свой справочник мест:** площадки, помещения и стойки добавляются в приложении кнопкой
  «+ Добавить». Долгое нажатие переименовывает или удаляет. Для каждой площадки можно выбрать,
  как называются помещения: «Машзал» или «Помещение». Справочник хранится в зашифрованной базе,
  а новые места из записей попадают в него автоматически.
- **Размещение устройства:** стойка, юнит, высота в U.
- **Оборудование:** тип (быстрый выбор: сервер, коммутатор, СХД, ИБП (UPS), PDU…), производитель из списка
  или вручную, модель, hostname, инвентарный номер. Если выбрать **YADRO**, сразу раскрывается
  список моделей: VEGMAN S220 (2U), VEGMAN S320 (3U), X2-205 (2U). При выборе модели
  высота в U и тип подставляются автоматически.
- **Фотографии:** снимок камерой или выбор из галереи. Фото уменьшаются до 1920 px и
  уходят вложениями в письме.
- **MGMT-интерфейс:** IP-адрес, маска/префикс, шлюз. Формат IP проверяется, но отправку это не блокирует.
  **В письме первый октет IP скрывается:** `192.168.1.50` → `*.168.1.50`, в том числе в комментариях
  и подключениях. В приложении и журнале адреса хранятся полностью.
- **Серийные номера:** любое количество. Можно ввести вручную или **отсканировать камерой**
  QR-код или штрихкод (Code128, DataMatrix и др.).
- **Подключения:** таблица «порт этого устройства → устройство → порт устройства → кабель/примечание».
  У новой строки устройство подставляется из предыдущей.
- **Все поля необязательные.** В письмо попадают только заполненные.
- **Тема письма:** префикс, оборудование, дата и время, например
  `[Инвентаризация] Сервер YADRO VEGMAN S220 · 02.10.2026 14:35`. Место установки
  указано в теле письма.
- **Отправка по e-mail через SMTP:** HTML-письмо в фирменной сине-голубой гамме и текстовая
  версия для простых почтовых клиентов.
- **Журнал:** все сохранённые и отправленные записи хранятся на телефоне. Есть поиск по S/N, IP,
  модели и стойке. Запись можно открыть, исправить и отправить повторно. Если отправка
  не удалась, данные не теряются: запись помечается как «Ошибка».
- После успешной отправки форма очищается, а площадка, помещение и стойка остаются
  для следующего устройства.
- Незаконченная запись сохраняется автоматически и не теряется, если приложение закрылось.

## Подсказки и справочник

Приложение запоминает производителей, модели (отдельно для каждого производителя), типы
оборудования, устройства в подключениях и свои типы кабеля. При вводе подсказки ищутся без учёта
регистра: `kr` или `Kra` → `Kraftway`. Часто используемые значения идут первыми. Ненужное значение
убирается крестиком в списке подсказок.

## Сканер

Сканер QR-кодов и штрихкодов умеет зум (ползунок, кнопки ×1/×2/×4, жест двумя пальцами) и фонарик.

## Зашифрованная база и вход по паролю

При первом запуске приложение предлагает:

- **Создать новую базу.** Выбираете папку (по умолчанию `Documents`) и задаёте пароль не короче 8 символов.
- **Открыть существующую.** Выбираете файл `dc-inventory.dcdb` и вводите пароль, например после
  переустановки или на другом телефоне.

Устройство защиты:

- Все данные лежат в одном файле `dc-inventory.dcdb`: журнал, настройки SMTP вместе с паролем,
  место установки и справочник. Файл зашифрован **AES-256-GCM**, ключ получается из пароля
  через PBKDF2-HMAC-SHA256 (310 000 итераций). Без пароля файл не прочитать, изменённый файл
  не откроется.
- Рабочая копия базы зашифрована тем же паролем и хранится внутри приложения. Файл в выбранной
  папке обновляется автоматически и остаётся после удаления приложения.
- Фотографии и черновик зашифрованы отдельным случайным ключом, который хранится внутри базы.
  Расшифрованные копии фото создаются только на время отправки письма.
- Вход в приложение по паролю базы. Если приложение свёрнуто дольше 5 минут, оно блокируется.
  Кнопка «Заблокировать» есть в настройках.
- Резервирование Android и перенос данных на другое устройство отключены. Скриншоты и превью
  в списке недавних приложений запрещены.
- **Пароль невозможно восстановить.** Если его забыть, базу можно только удалить с телефона.
- Данные версии 1.x переносятся в новую базу автоматически, после чего незашифрованные файлы
  удаляются. Старую копию `dc-inventory-backup.json` тоже можно открыть, чтобы перенести данные.

«Настройки → База данных»: сохранить базу в другую папку, сменить пароль, сделать копию базы.

## Настройки SMTP

«Настройки» (шестерёнка в шапке):

| Поле | Пример |
|---|---|
| Адрес сервера | `smtp.company.ru` |
| Шифрование | Нет / STARTTLS / SSL/TLS (порт подставляется автоматически: 25 / 587 / 465) |
| Порт | `587` |
| Не проверять сертификат | Включить для внутреннего сервера с самоподписанным сертификатом |
| Логин / пароль | Пусто, если сервер принимает почту без авторизации |
| Адрес отправителя | Если пусто, используется логин |
| Получатели | Любое количество, каждый адрес в отдельном поле |
| Копия (CC) | Необязательно, любое количество |
| Префикс темы | `[Инвентаризация]` |

Кнопка «Тест» отправляет тестовое письмо с текущими настройками.
Пароль хранится зашифрованным ключом из Android Keystore.

## Версии

Каждое изменение повышает номер версии (`appVersion` в `app/build.gradle.kts`) и добавляет
раздел в [CHANGELOG.md](CHANGELOG.md). Новая функция меняет среднюю цифру (2.1.0 → 2.2.0),
исправление — последнюю (2.1.0 → 2.1.1). В приложении версия видна в «Настройки → О приложении»,
после обновления показывается окно «Что нового».

## Сборка и подпись

Требования: JDK 17 и Android SDK (проще всего через Android Studio).

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions собирает APK при каждом пуше:

- **Если заданы секреты подписи**, собирается release, подписанный постоянным ключом. APK
  `dc-inventory-<версия>.apk` публикуется на странице
  [Releases](https://github.com/Onizyka/claude/releases) с описанием изменений из CHANGELOG.md.
  Обновления ставятся поверх без удаления.
- **Если секретов нет**, собирается debug-сборка (артефакт `dc-inventory-<версия>-debug`).

Секреты (Settings → Secrets and variables → Actions):

| Секрет | Значение |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | файл ключа `.jks` в base64 |
| `SIGNING_STORE_PASSWORD` | пароль хранилища ключей |
| `SIGNING_KEY_PASSWORD` | пароль ключа (для PKCS12 тот же) |
| `SIGNING_KEY_ALIAS` | псевдоним ключа |

Ключ `.jks` в репозиторий не добавляется. Если его потерять, установленные копии нельзя будет обновить
без удаления приложения.

Минимальная версия Android: 8.0 (API 26). Сервисы Google Play не нужны: сканер работает на ZXing.

## Стек

Kotlin, Jetpack Compose (Material 3), Navigation Compose, kotlinx.serialization (журнал в JSON),
ZXing Android Embedded (сканер), JavaMail for Android (SMTP).
